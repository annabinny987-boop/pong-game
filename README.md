# Pong Game

A simple two-player Pong game made using Godot Engine as part of the 20 Games Making Challenge.

# Game Features

- Two-player Pong gameplay
- Player 1 and Player 2 paddles
- Ball movement and bouncing
- Paddle and wall collisions
- Score system
- Winning condition
- Restart option
- Simple game-over screen

#Controls

 Player 1
- W – Move Up
- S – Move Down

Player 2
- ↑ Up Arrow – Move Up
- ↓ Down Arrow – Move Down

Restart
- R Restart the game

#Engine Used

Godot Engine

The game was created using Godot and GDScript.

# What I Learned

Through this project, I learned the basics of game development, including:

- Creating a 2D game in Godot
- Using GDScript
- Handling keyboard input
- Moving game objects
- Implementing ball physics and bouncing
- Detecting collisions
- Creating a scoring system
- Managing game states and restarting the game
- Debugging problems in a game

# Challenges Faced

The main challenges I faced were getting the ball movement and player controls working correctly. I also had issues with the restart function and debugging the game when the ball was not moving.

By debugging the code and testing different parts of the game, I was able to fix these problems and complete the game.



Made as part of the 20 Games Making Challenge.
